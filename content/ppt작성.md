# PPT 단축키 모음

| 기능 | 윈도우 | 맥 |
| --- | --- | --- |
| 복사 | `Ctrl + C` | `Cmd + C` |
| 붙여넣기 | `Ctrl + V` | `Cmd + V` |
| 복제 | `Ctrl + D` / `Ctrl + 드래그` | `Cmd + D` |
| 수직 or 수평 유지하며 복제 | `Ctrl + Shift + 드래그` | `Ctrl + Shift + 드래그` |
| 수직 or 수평 유지하며 이동 | `Shift + 드래그` | `Shift + 드래그` |
| 서식 복사 | `Ctrl + Shift + C` | `Cmd + Shift + C` |
| 서식 붙여넣기 | `Ctrl + Shift + V` | `Cmd + Shift + V` |
| 실행 취소 | `Ctrl + Z` | `Cmd + Z` |
| 다시 실행 (실행 취소를 취소) | `Ctrl + Y` | `Cmd + Y` |
| 그룹화 | `Ctrl + G` | `Cmd + Option + G` |
| 그룹화 취소 | `Ctrl + Shift + G` | `Cmd + Option + Shift + G` |
| 전체 선택 | `Ctrl + A` | `Cmd + A` |
| 슬라이드쇼 (첫 슬라이드부터) | `F5` | `Cmd + Shift + Enter` |
| 슬라이드쇼 (선택한 슬라이드부터) | `Shift + F5` | `Cmd + Enter` |
| 슬라이드쇼 끝내기 | `Esc` | `Esc` |
| 새 슬라이드 추가 | `Ctrl + M` | `Cmd + Shift + N` |
| 텍스트 오른쪽 정렬 | `Ctrl + R` | `Cmd + R` |
| 텍스트 왼쪽 정렬 | `Ctrl + L` | `Cmd + L` |
| 텍스트 가운데 정렬 | `Ctrl + E` | `Cmd + E` |
| 텍스트 크기 줄이기 | `Ctrl + [` | `Cmd + Shift + <` |
| 텍스트 크기 키우기 | `Ctrl + ]` | `Cmd + Shift + >` |
| 텍스트 밑줄 | `Ctrl + U` | `Cmd + U` |
| 파일 저장 | `Ctrl + S` | `Cmd + S` |
| 파일 다른 이름으로 저장 | `F12` | `Cmd + Shift + S` |
| 도형 비율 유지하며 확대 및 축소 | `Shift + 모서리 드래그` | `Shift + 모서리 드래그` |
| 하이퍼링크 삽입 | `Ctrl + K` | `Cmd + K` |
| 텍스트/도형 회전(15도씩) | `Alt + 좌우 방향키` | `Option + 좌우 방향키` |

# 효율을 높여주는 PPT 세팅법

## [1] 자주 쓰는 기능 상단 고정

경로: **`[파일]` > 좌측 하단 `[옵션]` > `[빠른 실행 도구 모음]`**

### 상단 고정 추천 기능

1. 가로 간격을 동일하게
2. 세로 간격을 동일하게
3. 가로 가운데 맞춤
4. 세로 가운데 맞춤
5. 개체 아래쪽 맞춤
6. 개체 위쪽 맞춤
7. 개체 오른쪽 맞춤
8. 개체 왼쪽 맞춤
9. 뒤로 보내기
10. 맨 뒤로 보내기
11. 앞으로 가져오기
12. 맨 앞으로 가져오기
13. 수직 뒤집기
14. 수평 뒤집기
15. 저장
16. 다른 이름으로 저장

## [2] 자동 저장 설정

경로: **`[파일]` > 좌측 하단 `[옵션]` > `[저장]` > `[자동 복구 정보 저장 간격]` 체크 > `[저장 간격]` 5분으로 설정**

## [3] 실행 취소 횟수 늘리기

경로: **`[파일]` > 좌측 하단 `[옵션]` > `[고급]` > `[실행 취소 최대 횟수]` 기본 20회 → 100회로 변경**

## [4] 슬라이드 크기 확인 및 설정

경로: **`[디자인]` > `[슬라이드 크기]`**

# 폰트 설치 방법

- **윈도우**: 폰트 파일 다운로드 → `내 PC` > `Windows` > `Fonts` 폴더에 글꼴 파일 넣기
- **맥**: 폰트 파일 다운로드 → 폰트 파일 클릭 → `[서체 설치]` 클릭
