01 / IF-STATUS

Interface 상태 확인

GMES·BESTERP 인터페이스별 실행 이력과 최근 처리 결과를 한 화면에서 확인합니다.

  • IF_ID · IF_STATE · 처리 건수 등 실행 이력 컬럼 조회
  • 최근 실행일시·에러 건수로 이상 유무 즉시 파악

04 / TDS-BUILDER

TDS 빌더

✦ AI

SQL 실행 결과를 분석해 Visual Studio C# Typed DataSet(.xsd)에 DataTable과 컬럼 Caption을 자동으로 채워 넣습니다.

  • SQL 실행 → 컬럼명·타입 자동 추출 후 xs:decimal/xs:string 매핑
  • AI가 원본 테이블을 역추적해 컬럼 설명(Caption) 자동 완성
  • 기존 XSD 미리보기에서 Caption 인라인 편집 · 엑셀 복사
  • 로컬 XSD 파일을 브라우저에서 바로 저장
