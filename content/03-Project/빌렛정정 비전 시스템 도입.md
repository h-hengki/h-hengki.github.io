# 시나리오

## 1. 소재 접근시 비전은 L2에 소재 정보 요청.
### 방향 : 비전 → L2
### - 명령어
| 필드 | 타입 | 설명 |
|------|------|------|
| `cmd` | string | 명령어. `"nextheat"` 고정 |
### - 예시
 ```
 {"cmd":"nextheat"}
 ```
## 2. Level2는 nextheat 명령어를 받아 다음 소재정보 전송.
### 방향 :  L2 → 비전
### - 최상위 
| 필드 | 타입 | 설명 |
|------|------|------|
| `cmd` | string | 명령어. `"nextHeatInfo"` 고정 |
| `data` | array | 소재 정보 테이블. 최대 5건 |
### - data 항목
| 필드 | 타입 | 설명 |
|------|------|------|
| `seq` | number | 순번. 전문 내 1부터 순차 부여. 항상 마지막 5개 값을 전송하며, 남은 값이 5개 미만이면 데이터 개수가 줄어듦 |
| `group_id` | string | 이번 HEAT의 그룹 아이디 |
| `pon` | string | 수주처 번호 |
| `heat_no` | string | HEAT 번호. 인식 키 |
| `heat_count` | number | HEAT 카운트 |
| `heat_max_count` | number | 전체 HEAT 개수 |
| `steel_grade_name` | string | 강종명 |

## 3. 비전은 Level2값과 비전 값을 비교하여 결과를 리턴.
### 방향 : 비전 → L2
### - 최상위 
| 필드 | 타입 | 설명 |
|------|------|------|
| `cmd` | string | 명령어. `"resultInfo"` 고정 |
| `data` | array | 소재 정보 테이블. 최대 5건 |
### - data 항목
| 필드 | 타입 | 설명 |
|------|------|------|
| `seq` | number | 순번. 전문 내 1부터 순차 부여. 항상 마지막 5개 값을 전송하며, 남은 값이 5개 미만이면 데이터 개수가 줄어듦 |
| `ord_group_id` | string | 작업지시한 HEAT의 그룹 아이디 |
| `ord_pon` | string | 작업지시한 수주처 번호 |
| `ord_heat_no` | string | 작업지시한 HEAT 번호. 인식 키 |
| `ord_heat_count` | number | 작업지시한 HEAT 카운트 |
| `ord_heat_max_count` | number | 작업지시한 전체 HEAT 개수 |
| `ord_steel_grade_name` | string | 작업지시한 강종명 |
| `rst_heat_no` | string | 비전이 인식한 HEAT 번호 |
| `rst_judgment` | string | 비전 판정 결과 (예: `"OK"`) |
| `rst_judgment_time` | string | 비전 판정 시간 (yyyy-MM-dd HH:mm:ss) |
