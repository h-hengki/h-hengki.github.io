## 디스크 구성 (LVM, UEFI 부팅)

| 마운트 | 디바이스 | 크기 | 사용 | 가용 |
|---|---|---|---|---|
| `/` | /dev/mapper/rl-root | 70G | 6.0G (9%) | 64G |
| `/home` | /dev/mapper/rl-home | 221G | 18G (8%) | 204G |
| `/boot` | /dev/sda2 | 960M | 449M | 512M |
| `/boot/efi` | /dev/sda1 | 599M | 9.0M | 590M |

- 총 약 300GB. 가용 공간 충분 (루트 64G + home 204G).
- 컨테이너 이미지/볼륨 저장소는 기본적으로 `/var/lib/containers`(podman) 또는
  `/var/lib/docker`(docker)로 루트 볼륨(70G)에 위치 — 3종 이미지 합계 약 2~3GB 수준이라 여유 있음.
  데이터가 커지면 `/home` 쪽으로 저장 경로 이전 검토.
- `/run/user/1000~1003` 존재 → root 외 일반 사용자 계정 4개가 있는 서버 (호스팅 용도 공유 가능성).

## 확인 필요 항목 (수집 예정)

아래 명령 결과가 나오면 이 문서에 추가한다.

```bash
# CPU
lscpu | grep -E "^CPU\(s\)|Model name|Socket|Core"

# 메모리
free -h

# 디스크
df -h
lsblk

# 네트워크 / 인터넷 접근 가능 여부 (폐쇄망이면 오프라인 설치 필요)
ip addr
curl -sI https://hub.docker.com | head -1

# 컨테이너 런타임 설치 여부
podman --version
docker --version

# SELinux / 방화벽 상태
getenforce
firewall-cmd --state && firewall-cmd --list-all
```

| 항목 | 내용 |
|---|---|
| CPU | ✅ Xeon Silver 4208, 8 vCPU (VMware) |
| 메모리 | (미확인 — /dev/shm 3.8G로 보아 약 8GB 추정, `free -h`로 확정 필요) |
| 디스크 | ✅ 아래 표 참고 |
| IP / 네트워크 | (미확인) |
| 인터넷 접근 (폐쇄망 여부) | ✅ 인터넷 가능한 회사망 — 온라인 설치 가능 (dnf, 컨테이너 이미지 pull 직접 수행) |
| 컨테이너 런타임 | ✅ Docker CE 29.6.1 + Compose plugin 5.3.1 설치 완료 (2026-07-14) |
| SELinux | (미확인) |
| 방화벽 | (미확인) |
